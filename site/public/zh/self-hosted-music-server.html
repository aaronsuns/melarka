自建音乐服务器：给全家用，一条命令装好

自建音乐服务器的好处是音乐留在自己手里，不用订阅，也不会下架。Melarka 把服务器和手机 App 一起做好了：装好之后，全家人各自用自己的账号听歌。

需要什么

  • 一台一直开着的 Linux 电脑或 NAS（amd64 或 arm64），装有 Docker 和 Docker Compose v2。一台小型家用服务器，或树莓派级别的机器，够一个家庭用。
  • 一个音乐文件夹（FLAC、MP3、AAC/M4A、Ogg、Opus、WAV 等 ffmpeg 能读的格式）；没有也行，可以之后从 YouTube 下载。
  • 手机上使用：一个域名，加 HTTPS 反向代理（iPhone App 必须用 HTTPS）。

一条命令安装

在服务器上运行下面的命令，最后换成你的音乐文件夹路径；不加路径，音乐就放在 ~/melarka/music。安装脚本会配好 Docker Compose 服务（普通用户装在 ~/melarka，root 装在 /srv/melarka）、启动，并打印地址和管理员密码。

curl -fsSL https://raw.githubusercontent.com/aaronsuns/melarka/main/deploy/install.sh | sh -s -- /path/to/your/music

然后：

  1. 在服务器上打开 http://127.0.0.1:4600，用 admin 和打印出来的密码登录。
  2. 在 管理 → 用户 里给家人建账号。
  3. 手机上用之前，配好 HTTPS（README 有 Caddy 和 nginx 示例），再装 App。

全家每人一个账号

每个人有自己的收藏、歌单、播放历史、私人电台和每晚的「为你推荐」，界面语言也各自选（English、简体中文、繁體中文、svenska）。曲库是共享的：谁下载的好歌，全家都能听到。

同步歌词、离线缓存、车载播放

  • 同步歌词：来自文件本身、旁边的 .lrc 或在线歌词源（默认 LRCLIB、网易云、QQ 音乐、酷狗）；歌词唱早了唱晚了，谁都能点一下对齐。
  • 离线缓存：收藏的歌在 Wi-Fi 下缓存到手机，隧道里没信号也能听。
  • 车载：安卓 App 可在手机连上车载蓝牙时自动播放收藏；iPhone 用「快捷指令」自动化实现。车机屏幕显示当前这句歌词。

在中国大陆使用

你自己的音乐、歌词和 App 不需要任何代理。YouTube 搜索、下载和频道被屏蔽，需要在服务器上配置代理，手机不需要。网易云、QQ 音乐、酷狗是非官方接口，可能随时失效，可以在 lyrics.providers 里去掉。详见 docs/install.md。

备份和升级

备份 data/lark.db（运行中请用 sqlite3 data/lark.db ".backup 文件名.db"）、channels/、youtube/、config.yaml 和 .env。你自己的音乐目录从不会被改动。升级：重新运行安装命令，或 docker compose pull && docker compose up -d。

常见问题

自建音乐服务器需要什么设备？

一台一直开着、装了 Docker 的 Linux 电脑或 NAS（amd64 或 arm64）。一台小型家用服务器就够一个家庭用。

会改动我的音乐文件吗？

不会，Melarka 只读取。改过的歌名、标签和歌词存在它自己的数据库里。

手机上怎么用？

有 iPhone、安卓原生 App 和网页版。手机在外面使用需要给服务器配 HTTPS 地址。

要钱吗？

不要，开源免费，也不需要在我们这里注册。
