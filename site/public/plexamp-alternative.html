A Plexamp alternative that is fully open source

Plexamp is a polished music player, and Plex Media Server is a mature product. People look for a Plexamp alternative for different reasons: they want open source software, no account with a third party, or a server that is only about music. Here is where each one is stronger.

Where Plexamp and Plex are better

  • Polish and analysis features. Plexamp is a long-running, carefully designed music app with audio-analysis based features that Melarka does not try to match.
  • One server for everything. Plex also serves video and photos, with apps on TVs and many devices.
  • Scale and support. It is a company product with a large user base.

Where Melarka fits

  • Open source (AGPL-3.0). You can read, build and change all of it: server, web app, iPhone app and Android app. Plex's server is proprietary.
  • No account with a third party. You create the accounts on your own server. Melarka contacts only what you use (YouTube, lyrics services, Last.fm if configured) sends an anonymous weekly install count to this website (switch it off in Admin, System), and asks GitHub once a day whether a newer Melarka exists (LARK_UPDATE_CHECK=off stops that).
  • Free. Some Plexamp features are tied to a paid Plex Pass or Plexamp Pass (check Plex's current terms). Melarka has no paid tier.
  • Family accounts for music. Favorites, playlists, history, radio and language are per person.
  • YouTube downloads built in, and synced lyrics with a way to fix timing.
  • Car autoplay that starts your favorites when the phone connects to the car.

The honest downsides of Melarka

Melarka is newer and smaller. It has no TV or console apps, no video library for your own films and no audio-analysis features. The iPhone app is not in the App Store, which means a one-time setup with your Apple ID and, for a free Apple ID, a weekly re-sign that is automatic with the Mac method. If those matter to you, stay with Plex.

Moving over from Plex

Your files are the portable part. Point Melarka at the same music folder; it only reads it. Plex's ratings and playlists do not transfer, so plan to rebuild favorites. You can run both for a while and compare. Related: Jellyfin music alternative, Navidrome alternative.

FAQ

Is Melarka free?

Yes, free and open source. There is no paid tier.

Do I need an account with a company to use Melarka?

No. You create the accounts on your own server. The only things it sends out are an optional anonymous weekly install count and a daily request to GitHub for the latest release number, which carries nothing about your install.

Can Melarka use my Plex music folder?

Yes, it can read the same files. Playlists and ratings stored in Plex do not carry over.

Is there a desktop app?

Melarka is used from a browser on a computer; the native apps are for iPhone and Android.
