**标题：** 订阅 Spotify 越来越贵，我自己做了个家庭音乐服务器，用了几个月把它换掉了

**正文：**

先说结论：我们家现在不订 Spotify 了，音乐都放在家里的电脑上，用自己做的开源软件 **Melarka** 在手机上听。这不是适合所有人的方案，下面说清楚它能做什么、不能做什么。

[图: zh_cover.png]

**起因**

我住在瑞典，家里两个孩子，每天开车上下班。订 Spotify 家庭套餐，遇到三件小事：涨价；歌单里的歌有时候变灰、下架；开车连蓝牙还要手动点开 App。

**我们家怎么用**

1. **歌从哪来**：在 YouTube 上搜歌下载（单曲或歌单），或者直接用你本地的音乐文件夹。下载下来是自己的文件。
2. **开车**：手机一连上车载蓝牙，收藏的歌自动开始播放，车机上显示歌词。
3. **没信号**：收藏的歌缓存在手机里，走进没信号的地方照样听。
4. **全家共用**：每人一个账号，各自的收藏、歌单、私人电台互不混；小朋友点一下就能切账号，不用密码，孩子听的歌不会混进大人的推荐里。
5. **歌词**：逐行同步，对不上可以手动对齐。

[图: zh_favorites.png]

[图: zh_users.png]

**它的缺点，先说在前面**

- 需要一台长期开着的电脑或 NAS，会用 Docker 更方便。不想折腾的人，订阅服务更省心。
- 没有 Spotify 那样的海量曲库和算法推荐，歌要自己下载或放进文件夹。
- 从 YouTube 下载内容是否合适，取决于你所在地区的法律和你下载的内容，请自行判断。
- iOS 版目前需要一台 Mac，用 Xcode 和自己的 Apple ID 装到手机上（没有上架 App Store）；安卓版直接装 APK。
- 它还很年轻，我能看到的匿名统计里大约二十来个安装，肯定有没想到的毛病，欢迎到 GitHub 提 issue。

**怎么装**

Docker 一条命令，完整步骤在项目主页：

- 网站（中英文、有演示视频）：https://melarka.zexa.se
- 源码：https://github.com/aaronsuns/melarka（开源，AGPL）

项目是我在 AI 编程助手的帮助下开发的，代码和文档都经过我自己的测试和修改。
